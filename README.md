# 하루계산기: 광고 수익형 무료 계산기 사이트

## 수익 구조

```
검색 (퇴직금 계산, 주휴수당 계산 …) → 계산기 페이지 방문 → 자동 광고 노출 → AdSense 수익
```

- **운영비 0원:** GitHub Pages 무료 호스팅을 씁니다. 도메인을 사면 연 1~2만원이 추가됩니다(권장).
- **유지보수 거의 없음:** 서버, DB, 회원 기능이 없는 정적 사이트입니다. 계산 공식은 법이 바뀌지 않는 한 그대로 쓸 수 있습니다.
- **연 1회 확인할 것:** 최저시급 값(현재 2026년 10,320원). `tools/weekly-holiday-pay.html`, `tools/wage-converter.html`에 들어 있습니다.

## 들어 있는 계산기 (11개)

| 분류 | 계산기 |
|---|---|
| 직장·급여 | 퇴직금, 연차, 주휴수당, 시급·월급·연봉 변환 |
| 금융 | 대출이자 (원리금균등/원금균등/만기일시), 예금·적금 이자 |
| 생활 | 만 나이, D-day·기념일, 평수, 퍼센트, BMI |

모든 계산은 이용자의 브라우저 안에서 이루어집니다. 계산기마다 공식, 근거, FAQ 설명글이 붙어 있어서 검색 노출과 AdSense 심사에 유리합니다.

## 직접 해야 하는 일 (계정·본인 인증이 필요한 일)

| 순서 | 할 일 | 걸리는 시간 | 비용 |
|---|---|---|---|
| 1 | GitHub에 배포 (Claude가 대신 할 수 있음, 승인만 필요) | 5분 | 0원 |
| 2 | (권장) 도메인 구입 후 GitHub Pages에 연결 | 15분 | 연 1~2만원 |
| 3 | [Google Search Console](https://search.google.com/search-console)과 [네이버 서치어드바이저](https://searchadvisor.naver.com)에 사이트 등록, 인증 코드를 `config.json`에 입력, `sitemap.xml` 제출 | 20분 | 0원 |
| 4 | 방문자가 조금 생기면(보통 2~4주 뒤) [Google AdSense](https://adsense.google.com) 신청 | 10분 | 0원 |
| 5 | 승인되면 `ca-pub-…` ID를 `config.json`의 `adsense_client`에 넣고 푸시, AdSense에서 '자동 광고' 켜기 | 5분 | 0원 |

`config.json`을 고치고 `main`에 푸시하면 GitHub Actions가 알아서 다시 빌드하고 배포합니다.

## 현실적인 기대치

- 검색 노출은 보통 **1~3개월** 뒤부터 생기고, 트래픽이 의미 있게 쌓이기까지는 **3~6개월 이상** 걸립니다.
- 국내 AdSense 수익은 대략 **페이지뷰 1,000회당 1,000~3,000원** 정도로 알려져 있습니다. 하루 1,000뷰면 월 3~9만원 수준입니다.
- 수익이 나지 않을 수도 있습니다. 경쟁 사이트가 많은 키워드도 있어서 보장된 수익은 없습니다.
- 수익을 키우는 방법은 **계산기 수를 늘리는 것**입니다(실수령액, 4대보험, 양도세, 전역일 계산기 등). 하나 추가할 때마다 검색 유입 경로가 하나씩 늘어납니다.

## 계산기 추가하는 법

`tools/`에 HTML 조각 파일을 하나 만들면 됩니다. 맨 위에 JSON 메타데이터 주석을 넣고, 폼과 스크립트를 쓴 다음, `<!-- guide -->` 아래에 설명글을 씁니다. 기존 파일을 복사해서 시작하면 됩니다. 메인 페이지, 관련 계산기 링크, 사이트맵은 `build.py`가 자동으로 만듭니다.
